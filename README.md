# Infinity-Metalique
O Infinity Metalique é uma plataforma que centraliza todas as ferramentas e informações da empresa em um único lugar. Com ela, é possível gerenciar processos, acompanhar indicadores, acessar documentos, integrar setores e otimizar a rotina de trabalho, proporcionando mais organização, produtividade, agilidade e eficiência para toda a equipe
